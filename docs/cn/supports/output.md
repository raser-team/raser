# 输出归属

_位于 `src/raser/supports/output.py` 的 RASER 5.0 文件系统操作_

---

## 📋 职责

Output 将声明的所属者与相对标签映射到当前项目下，创建明确请求的目录并执行范围明确的文件操作。调用者提供文件名、序列化领域数据并判断工作流完成状态。

## 🗂️ 命名空间

| 所属者 | 命名空间 |
| --- | --- |
| 应用工作流 | `<project>/<workflow>/<run_id>/...` |
| 直接 Core 命令 | `<project>/<core-subsystem>/...` |
| 外部调用者 | `<project>/<declared-owner>/...` |

标签是限制在当前项目下的相对路径段。绝对路径标签与向父目录逃逸的标签无法通过校验。

应用创建运行根目录，并向 Core 传入明确的产物目标。直接 Core 命令可要求 Core 推导子系统命名空间。应用调用明确提供其产物目标。

## ⚙️ 操作

路径计算与修改是两项独立契约：

- [Paths](paths.md) 计算项目位置与逻辑位置
- Output 创建指定目录或移除指定文件
- 调用者持有文件格式、序列化与科学校验
- 权限、存在性与 I/O 失败继续向上传播

生成的数据保存在当前项目下，或保存在调用者明确持有的另一目标位置。

## ⚠️ 失败契约

绝对路径标签与向父目录逃逸的标签在修改前失败。当前项目之外的操作会被拒绝。覆盖与移除需要明确许可相应操作。部分完成的文件系统工作对调用者保持可见。
