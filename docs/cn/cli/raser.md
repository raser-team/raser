# RASER CLI 路由器

_RASER 5.0 命令解析、分发上下文与进程退出语义_

---

## 📋 范围

安装后的 `raser` 入口负责命令语法与分发。它将参数向量转换为一个选定的应用或 Core 能力，并使命令行事务与科学代码分离。

| 方面 | CLI 职责 | 下游职责 |
| --- | --- | --- |
| **语法** | 解析命令、选项和值 | 解释科学含义 |
| **路由** | 选择一个已注册模块和可调用对象 | 执行所选能力 |
| **上下文** | 激活项目与应用组件根目录 | 通过 Supports 解析输入 |
| **批处理** | 识别整条命令的提交 | 选择工作流展开与收集方式 |
| **退出** | 返回所选状态并保证清理 | 抛出或返回可见失败 |

探测器构造、物理默认值、结果解释和工作流执行属于所选应用或 Core 能力。CLI 在内部提供路由接口，并公开 [CLI 概览](README.md)所述的 `raser` 安装命令。

## 📥 输入与输出

### 输入

| 输入 | 契约 |
| --- | --- |
| **参数向量** | 传给 `raser` 的有序 token；分发期间保持结构 |
| **路由注册表** | 命令组、命令前缀、目标模块、可调用对象及参数投影 |
| **运行时环境** | 初始工作目录、项目、组件、容器及外部运行时设置 |

解析器默认值限于命令语法。应用配置和科学默认值在分发后由所属应用解析。

### 输出

有效调用产生以下一种结果：

| 结果类型 | 结果 |
| --- | --- |
| **直接分发** | 所选可调用对象执行一次 |
| **全局批处理** | 一条完整 `raser` 命令提交一次 |
| **帮助** | 在导入应用前打印帮助文本 |
| **失败** | 非零状态或异常到达调用者 |

CLI 返回前恢复临时环境上下文。所选应用或 Core 能力持有其生成的科学产物。

## ⚙️ 分发生命周期

```mermaid
flowchart LR
    accTitle: RASER CLI 分发生命周期
    accDescr: 命令经解析和路由后获得临时项目与组件上下文，通过一次延迟导入完成分发，并在返回状态前清理。

    receive_args([📥 接收参数 token]) --> parse_command[⚙️ 解析命令语法]
    parse_command --> select_route[📋 选择一条路由]
    select_route --> activate_context[🔧 激活运行时上下文]
    activate_context --> derive_arguments[⚙️ 推导上下文参数]
    derive_arguments --> import_entry[📦 导入所选入口]
    import_entry --> invoke_entry[⚡ 调用所选入口]
    invoke_entry --> release_runtime[🔧 释放运行时资源]
    release_runtime --> return_status([✅ 返回入口状态])
```

成功调用、输入拒绝、下游异常与提交失败均执行清理。清理恢复先前的项目和组件变量，并在已加载 Geant4 全局管理器时按依赖顺序释放它们。

## 🔗 依赖方向

路由器可在启动时导入 Supports，并延迟导入所选应用或 Core 入口。延迟导入使大型科学运行时限于所选入口。

```text
用户 -> CLI -> 所选应用 -> Core
           \-> 所选 Core 能力
           \-> Supports
```

依赖规则如下：

- 依赖边从 CLI 指向 Applications 与 Core
- 应用接收解析后的顶层参数值
- Python 导入状态来自安装后的软件包与当前环境
- 每条路由指定一个具体模块和可调用对象
- Core 能力通过对应顶层命令公开

项目推断与组件查找见[运行时路径](../supports/paths.md)。工作流展开见 [Jobs](../supports/jobs.md)。

## 📦 路由描述

每个终端解析器注册一份完整的分发描述：

| 字段 | 含义 |
| --- | --- |
| **Command** | 稳定的所属命令，例如 `signal`、`field` 或 `metrics` |
| **Group** | 应用或 Core 能力 |
| **Prefix** | 工作流展开时标识 worker 命令的 token |
| **Module** | 一个可导入的目标模块 |
| **Callable** | 该模块上的一个函数 |
| **Projection** | 按位置传入的解析值，或完整的解析请求 |
| **Context selector** | 路由所需的项目输入与应用组件根目录 |

缺少描述字段属于注册错误。分发调用描述中记录的确切模块与可调用对象。

## ⚙️ 批处理边界

两种批处理表面具有不同所属者：

| 表面 | 所属者 | 契约 |
| --- | --- | --- |
| **全局批处理** | CLI | 提交一次完整的所选命令 |
| **索引任务** | 应用 | 将一次逻辑运行展开为多个索引 worker |

全局批处理准备移除 CLI 控制 token，并保留其余命令 token，直至集群适配器序列化任务文件。索引 worker 接收相同的路由前缀和规范化运行 ID，以及各自唯一的任务索引。

## ⚠️ 失败语义

| 失败 | 必需行为 |
| --- | --- |
| **无效语法** | 打印解析器诊断并以状态 `2` 退出 |
| **缺少命令** | 打印顶层帮助并返回状态 `1` |
| **未知路由目标** | 抛出原始导入或属性错误 |
| **入口拒绝** | 保留入口明确返回的非零状态 |
| **入口异常** | 恢复上下文、释放运行时资源并重新抛出 |
| **批处理拒绝** | 返回提交失败并标识部分提交 |
| **清理失败** | 暴露清理错误并返回失败 |

每个失败的应用、worker 或调度器操作均以失败状态到达进程边界。
