# RASER

> Version 5.0 · Python 3.11 · Semiconductor-detector simulation

RASER (**RA**diation **SE**miconducto**R**) connects detector fields, particle
interactions, induced-current calculation, electronics readout, and
experiment-level analysis through one command-line interface.
