# Metrics

_RASER 5.0 波形测量与事件统计_

Metrics 从采样波形计算物理量，并将电极测量组合为事件级观测量。输入包括波形样本、时间轴、读出布局及所选阈值。

## 波形测量

对于波形 `V(t)`，幅度为其最大绝对偏移。到达时间（ToA）为前沿阈值交点，过阈时间（ToT）为前沿与后沿交点之间的时间间隔。

对于恒比值 `f`，CFD 时间满足

```math
|V(t_{\mathrm{CFD}})|=fA,
```

其中 `A` 为波形幅度。相邻样本间的线性插值给出交点时间。波形积分记录为电荷。

每个电极分别提供幅度、ToA、ToT、电荷与 CFD 时间。通道阈值选择电极测量，事件幅度阈值选择用于组合观测量的事件。

## 电极组合

按照 Device 声明的二维读出布局组合通过选择的电极。携带信号的相邻电极构成一个簇。簇尺寸是该组中的电极数。

幅度、电荷和 ToT 均可作为簇位置的权重 `w_k`：

```math
\mathbf r_{\mathrm{cluster}}
=\frac{\sum_k w_k\mathbf r_k}{\sum_k w_k},
```

其中 `r_k` 为电极 `k` 的位置。给定的相互作用位置可得相应重建残差。事件 ToA 和 CFD 时间采用最早通过选择的电极交点。

## 事件数据

事件记录包含组合后的 ToA、ToT、幅度、电荷、CFD 时间、簇尺寸、重建位置与重建残差。

未定义的时间或位置值在事件记录中明确表示。计数和物理零值保留其数值含义。

## 统计分析

波形统计汇总事件记录。时间分布通过拟合宽度给出 ToA 与 CFD 分辨率。幅度、电荷与 ToT 分布提供相应拟合位置和宽度。簇尺寸与重建位置分布描述空间响应。

提供相互作用位置时，Metrics 比较重建位置与输入位置，并形成对应的残差分布。同一事件数据支持测量电荷共享与电极 pitch 内位置之间的 eta 标定。
