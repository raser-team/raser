# Frontend

_RASER 5.0 传感器与 AFE 电路仿真_

Frontend 将 Device 的感应电流源连接至其传感器电学模型与所选模拟前端（AFE）。联合电路求解产生指定 AFE 输出节点上的信号。

## 传感器电学输入

传感器电学输入描述连接至读出电极的网络。其中包括体电容、电极间耦合、偏置电阻、AC 耦合电容，以及所选传感器模型需要的数值。

这些数值可来自与所选 Field 配置关联的 Field AC 计算，也可来自 Device 声明。所选数值及其工作条件共同传入传感器建模。

## 传感器建模

传感器建模将电学输入转换为电路网表。网表公开 AFE 所需的读出电极、偏置连接与参考节点。接触和电极名称遵循 Device 定义。

电极间耦合与其他传感器阻抗共同表示在该网表中。因此，所得信号分布在已连接 AFE 呈现的阻抗下计算。

传感器网表声明各 Current 源使用的节点，以及呈现给各 AFE 通道的节点。电阻片生成器采用片尺寸、网格尺寸、方块电阻、背板电容、偏置电阻、偏置接触位置、耦合电容与读出接触位置。这些声明生成连接至 AFE 输入节点的片电阻与传感器电容。

## AFE 建模

AFE 网表定义输入阻抗、反馈、传递响应、带宽、噪声源与输出节点。它可直接提供，也可由参数化 AFE 定义生成。

Frontend 还接收单边 AFE 输出噪声谱。该频谱可来自 ngspice 噪声分析，也可来自明确的输入等效电压、电流、闪烁噪声、跨阻与带宽数值。Device 电容与 AFE 参数共同进入输入等效计算。

频谱采样至波形频率网格，并变换为实数时域波形。随机种子、谱密度单位、频率范围、均值及所需 RMS 归一化均为明确输入。

Frontend 将 Current 的每个电极电流转为电路电流源，同时保留其符号与时间轴。当前 ngspice 路径采用分段线性源。

## 电路组装与求解

Frontend 将每个感应电流源连接到对应传感器电极，将传感器输出端连接到相应 AFE 输入，并施加配置的偏置与参考连接。组装后的网表在瞬态域求解。

联合求解包含传感器耦合网络、AFE 输入呈现的负载及后续 AFE 级的响应。电极串扰由该求解得到。

## Frontend 输出

Frontend 返回各指定 AFE 输出节点的电压或电流波形。每条波形携带时间样本、数值单位及对应读出电极。这些波形作为 ADC 的模拟输入，以及 Metrics 使用的波形输入。
