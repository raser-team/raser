# ASIC 构思草稿

_非规范性设计说明_

`ASIC` 类在电路与几何仿真中描述同一个芯片。其项目目录保存可由 PCB 定义和应用场景引用的产物。

## 🧩 拟定职责

ASIC 定义持有联系以下内容的标识与映射：

- 电路仿真定义与可复用结果
- 物理几何与材料描述
- 焊盘、凸点与倒装焊装配细节
- 与已安装 PCB 和传感器共享的通道标识

电路行为与几何形态是同一 ASIC 的两种表示。其端口、通道、坐标系与版本均可追溯至同一定义。

## 🗂️ 候选产物分组

```text
<asic>/
├── asic.json
├── circuit/
│   └── <simulation-definitions-and-results>
├── geometry/
│   └── <geometric-products>
└── assembly/
    └── <flip-chip-and-bump-products>
```

这些分组是暂定的归属类别。后续契约将确定序列化器与 API。PCB 可引用特定 ASIC 定义及其兼容产物，这些内容仍由 ASIC 持有。

## ❓ 待确定的设计点

- 电路、几何和装配之间通用的通道与端口标识
- ASIC、凸点布局、PCB 封装与传感器通道之间的版本绑定
- 可复用电路表征与场景特定读出仿真的边界
- PCB 与探测器应用采用的运行时组合契约
